Did the agent earn its number?

InferenceBench scores the server an agent ships after a 2-hour session. BlameGraph replays the session and checks whether the agent measured what it shipped, kept what it measured, and reported it truthfully. 269 public runs, 23 agents, 4 scenarios, 3 seeds.
